# Ace Apps: concept sites

Five fictional-business concept websites designed and built by Ace Apps as portfolio pieces. Static HTML/CSS/JS, mobile-first, no frameworks. All pages are `noindex`. Forms are demos and send nothing.

- `/pharmacy/`: Linden & Vale Pharmacy (also available as a WordPress block theme: `/downloads/linden-vale.zip`)
- `/restaurant/`: Brasa & Fig
- `/barbershop/`: Ironwood Barber Co.
- `/accounting/`: Hartley & Rowe Accounting
- `/shop/`: Fern & Fable

Images are original AI-generated images made for these concepts. Fonts are from Google Fonts (OFL).
